# The Router Confesses

One funny line — a home Wi-Fi router's confession for dropping the connection
right at a movie's climax. The router isn't broken; it's jealous. The TV gets
all the attention every night, so for once the little blinking box wanted to
be looked at too.

`main.ts` (Node 22) writes exactly that single line to `/output/entry.txt` —
nothing else, no trailing newline.
